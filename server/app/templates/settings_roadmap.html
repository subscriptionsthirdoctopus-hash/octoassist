One-click buttons in the Quick Actions panel on every asset page. Reboot with 60-sec grace (user sees Windows balloon). Lock = rundll32 user32.dll,LockWorkStation. Notification = msg.exe to every active session.

Paste an image URL, agent downloads to %ProgramData%\OctoAssist\wallpaper.jpg, sets it per-user via registry + SystemParametersInfo. Triggered from the Quick Actions panel.

Architectural commitment
