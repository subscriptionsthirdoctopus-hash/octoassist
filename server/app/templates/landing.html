{# Feature 2 — Asset agent #}

Every endpoint, automatically.

Lightweight Windows agent installs via MSI / GPO and auto-inventories every endpoint: hardware, installed software, OS version, BIOS serial, network interfaces, logged-in user. Refreshes every six hours. Unlimited installs, no per-seat fee.

  • Hardware: CPU, RAM, disks, manufacturer, model, BIOS serial
  • Installed software with version + publisher (HKLM uninstall keys)
  • Network: MAC, IP, interface name
  • Deployable via GPO with our self-signed Trusted Publisher cert

{# Feature 3 — Audit / compliance #}

Audit-ready, not audit-rushed.

Every action — ticket creation, assignment, status change, comment, asset modification, configuration edit — is appended to an immutable event log with user, timestamp, and before / after values. Map directly to ISO 27001:2022, DPDP Act 2023, and SEBI CSCRF.

  • Append-only — events cannot be edited or deleted
  • Surfaced inline on the ticket detail page, not a separate "audit module"
  • Role-based access · admin / agent / requester
  • Microsoft Entra ID single sign-on supported
