Notifications

Mail provider

OctoAssist sends notifications via one of two paths. Pick the one that fits your tenant's policy. Microsoft Graph is preferred for M365 tenants — it doesn't need SMTP AUTH (which is blocked by default in modern M365).

Notification email

Microsoft email address for OctoAssist outbound notifications. Accepted domains: thirdoctopus.com, outlook.com, hotmail.com, live.com, msn.com, and any *.onmicrosoft.com tenant.

Outbound delivery uses the SMTP settings below.

SMTP — outbound email

Microsoft 365 default: host smtp.office365.com, port 587, STARTTLS, AUTH with a service-account mailbox. Modern M365 tenants block SMTP AUTH per-mailbox by default — enable it via Mail flow → SMTP AUTH per-mailbox first, or use an app password (outlook.com personal accounts). Password is stored as plain text — use a low-privilege service account, not your daily login.
