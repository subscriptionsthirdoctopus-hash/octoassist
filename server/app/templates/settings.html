SMTP — outbound email

Microsoft 365 default: host smtp.office365.com, port 587, STARTTLS, AUTH with a service-account mailbox. Modern M365 tenants block SMTP AUTH per-mailbox by default — enable it via Mail flow → SMTP AUTH per-mailbox first, or use an app password (outlook.com personal accounts). Password is stored as plain text — use a low-privilege service account, not your daily login.
