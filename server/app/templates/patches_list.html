Refresh agent on —

The new agent will auto-update on its next scheduled check-in (every 6 hours). To roll it out right now, RDP into the endpoint, open elevated PowerShell, and paste this one permanent command. It always pulls the latest refresh logic from the server — you never need to copy a different command, even after future updates. 

iex (iwr -useb https://octoassist.thirdoctopus.com/agent/refresh.ps1).Content

What this does (in one HTTPS fetch + run): installs missing PSWindowsUpdate + NuGet → pulls the newest octoassist_agent.py → locates real Python → runs --once to apply the Windows Update lock-down and post a fresh inventory + patch scan → tails the agent log.

After it finishes the endpoint reports back within ~30 seconds and this row will flip to ✓ Fully Updated or N pending.
