Push installer to endpoint(s)

Paste a public URL to the installer (Azure storage / SharePoint / corporate file server / vendor download link). The agent downloads it on the endpoint, runs it as SYSTEM with your silent-install args, then reports back.

Quick tips

  • .msi files run via msiexec /i. Default args: /quiet /norestart.
  • .exe installers use whatever the vendor documents:
    • NSIS (most apps): /S
    • InnoSetup: /VERYSILENT /SUPPRESSMSGBOXES /NORESTART
    • InstallShield: /s /v"/qn /norestart"
    • Adobe / Microsoft custom: see vendor docs
  • Endpoint must reach the URL over HTTPS (or HTTP) for the download to succeed.
  • Agent runs as SYSTEM — no UAC prompt, no user-side dialog.
  • Status updates within 30 seconds; result is in the table below.
