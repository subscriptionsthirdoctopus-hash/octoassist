💡 Tips

  • .msi files default args: /quiet /norestart
  • .exe installers:
    • NSIS: /S
    • InnoSetup: /VERYSILENT /SUPPRESSMSGBOXES
    • InstallShield: /s /v"/qn"
  • Endpoint must reach the URL over HTTPS.
  • Agent runs as SYSTEM — no UAC prompt.
  • Status updates within 30 seconds.
