Asset Agent — install on a host

Cross-platform Python agent. Downloads the script + the OS-specific installer.

Tenant enrolment key

{{ enrolment_key }}

Paste this into the install command below. After first check-in, each agent receives its own long-lived bearer token; the enrolment key is shared across the tenant.

Linux (Ubuntu / Debian / RHEL)

  1. Download both files to the target host: 
    curl -fsSL -o octoassist_agent.py "{{ server_url }}/agent/files/octoassist_agent.py"
curl -fsSL -o install-linux.sh    "{{ server_url }}/agent/files/install-linux.sh"
  2. Run the installer as root: 
    sudo bash install-linux.sh \
    --server-url={{ server_url }} \
    --enrolment-key={{ enrolment_key }}
  3. Verify: 
    systemctl status octoassist-agent
journalctl -u octoassist-agent -f

Windows (10 / 11 / Server 2019+)

  1. Make sure Python 3.10+ is installed (winget install Python.Python.3.12).
  2. Download both files. Open PowerShell as Administrator in the same folder: 
    Invoke-WebRequest -Uri "{{ server_url }}/agent/files/octoassist_agent.py" -OutFile octoassist_agent.py
Invoke-WebRequest -Uri "{{ server_url }}/agent/files/install-windows.ps1"  -OutFile install-windows.ps1
  3. Run the installer: 
    .\install-windows.ps1 `
    -ServerUrl {{ server_url }} `
    -EnrolmentKey {{ enrolment_key }}

Installs as a Task Scheduler job running as SYSTEM at boot. AV-friendly because it's stock python.exe running a .py file — no PyInstaller binary to scan.
