How this works

Curate the installers your team deploys regularly — Chrome, Acrobat Reader, the VPN client, internal LOB apps — once, with their silent-install args and (optionally) an uninstall command. They then appear in the Deploy software dropdown so the helpdesk picks a package + endpoints + clicks Queue deploy. No more pasting URLs and remembering vendor-specific silent flags every time.

Installer URL can be a public vendor link, an Azure Blob / SharePoint share, a corporate file server (must be HTTPS-reachable from the endpoint), or use the OctoAssist upload pipeline to host it.
