Install the OctoAssist agent on a Windows endpoint

One PowerShell line. Installs Python (if missing), the agent script, a Scheduled Task running as SYSTEM, and runs the first check-in.

Step 1 — Open an elevated PowerShell on the endpoint

Start menu → right-click Windows PowerShell → Run as administrator.

Step 2 — Paste this one line

iex (iwr -useb {{ server_url }}/agent/install.ps1).Content

The script auto-detects Python, installs it via winget if missing, downloads octoassist_agent.py to C:\Program Files\OctoAssist Agent\, writes config to C:\ProgramData\OctoAssist\agent.json, registers the OctoAssist Agent Scheduled Task running as NT AUTHORITY\SYSTEM, and runs the first check-in. The endpoint appears in /assets within a minute.

Step 3 — Verify

  • Open /assets — new hostname appears.
  • Open /patches — the endpoint's missing patches start surfacing on the next check-in (every 6 hours, or run --once manually).

What the agent reports

  • Hardware — CPU, RAM, disks, BIOS, manufacturer, model
  • OS — Windows edition, build, install date
  • Software inventory — installed apps from HKLM\...\Uninstall (Win32 + WOW6432)
  • Available updates — from winget upgrade (vendor-aware: Google, Adobe, Microsoft, Mozilla, etc.) and PSWindowsUpdate KBs
  • Logged-in user, network interfaces

Inventory + patches refresh every 6 hours. When a patch window is scheduled with auto-execute and the matching packages are approved, the agent pulls and installs them via winget upgrade --silent / Install-WindowsUpdate.

Uninstall on the endpoint

Unregister-ScheduledTask -TaskName "OctoAssist Agent" -Confirm:$false
Remove-Item -Recurse -Force "C:\Program Files\OctoAssist Agent","C:\ProgramData\OctoAssist"
