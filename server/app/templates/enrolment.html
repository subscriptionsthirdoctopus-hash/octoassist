MSI Install Command

msiexec /i OctoAssistAgent.msi ^
  SERVER_URL=https://octoassist.tema.local ^
  ENROLMENT_KEY={{ tenant.enrolment_key }} ^
  /qn /l*v %TEMP%\OctoAssistAgent.log

Notes

  • Replace SERVER_URL with the actual internal URL of this OctoAssist server.
  • The enrolment key is shared across all endpoints for this tenant. Each agent receives a unique long-lived token after first registration.
  • After install, the agent runs as the Windows Service OctoAssistAgent and checks in every 6 hours.
